These FreeMind-compatible `.mm` files are the source maps behind the homepage's six themes.

| Theme | File |
|---|---|
| Artificial intelligence & machine learning | [ai-top-conference-map.mm](ai-top-conference-map.mm) |
| Metal–organic frameworks | [mof-recent-progress-map.mm](mof-recent-progress-map.mm) |
| Robotics | [robotics-recent-progress-map.mm](robotics-recent-progress-map.mm) |
| AI for chemistry / materials | [ai-chemistry-materials-map.mm](ai-chemistry-materials-map.mm) |
| AI for life sciences | [ai-life-sciences-map.mm](ai-life-sciences-map.mm) |
| Mathematics | [mathematics-map.mm](mathematics-map.mm) |

To explore the maps visually, open a file in [FreeMind](https://freemind.sourceforge.io/) or Freeplane. The homepage presents the same collection as a compact web index.


The AI/ML theme is organised by research topic, not conference prestige or acceptance status. Conference names, publication years and preprint labels remain paper-level metadata. FrontierCS 2 belongs under Evaluation & Reliability → Research & Engineering Agent Benchmarks; a benchmark for agents is distinct from a method for building agents. The historical roadmap filename remains unchanged to preserve existing links.
