These FreeMind-compatible `.mm` files are the source maps behind the homepage's three themes.

| Theme | File |
|---|---|
| AI top conferences | [ai-top-conference-map.mm](ai-top-conference-map.mm) |

| Robotics | [robotics-recent-progress-map.mm](robotics-recent-progress-map.mm) |
