# AI／ML 论文图示核查

适用于已有讲解页审阅，以及新增或修改 AI 方法图、实验图表和教学演示。根据论文实际内容选用下列检查，不为没有相关机制的页面增加模块。

## 清点与来源

- 清点正文及各深度层次中的所有视觉模块：方法流程、树／图、注意力矩阵、向量空间、公式、数值卡片、柱图／散点图、结果表及动态输出。HTML／CSS 拼出的图同样需要核查。
- 在页面 `sources.md` 中按模块记录：页面位置／状态、原文版本与章节／图表位置、是否为原结果或教学演示、核对结论与已修正的问题。审阅报告区分“核对一致”“已修正”“示意且已说明”“资料不足”；不要把未验证项列为通过。
- 使用正式发表版本或明确指定版本，区分不同模型检查点、预印本修订和排行榜时间快照；跨来源取数时在图旁注明，不把后续版本的结果归给早期模型。

## 方法图与公式

- 对照正文、原图图注和算法一起核对输入／输出、箭头方向、循环、分支条件、停止条件及输出单位。区分训练数据构造、训练过程与推理时计算，避免将训练专用模型画成必需的推理组件。
- 注意力图核对行／列分别代表什么、Q／K／V 来源、遮罩作用位置、哪些位置可互相访问，以及汇聚发生于哪一步。可访问性矩阵应标明它表示遮罩；均匀着色不代表真实模型学到的注意力权重。
- 检索图核对一次查询得到的候选集合、文档条件生成与结果合并；区分逐 token 的潜变量边缘化和重新调用检索器，以及单文档条件项与最终多文档求和。检索先验与文档后验分开说明，后验热图不直接解释为硬文档选择轨迹。树图明确是完整搜索树、选中路径还是局部分支示例。
- 公式逐符号核对条件项、求和／乘积范围、归一化、概率与对数概率、奖励分段及阈值。若为教学简式或实际代码采用另一种写法，说明差异；不要换了公式仍沿用原方程编号。
- 概念节点数量、类别名称、图例与说明一致。交互状态改变后，连线、步骤解释与控制条件仍需对应原方法。

## 实验图表

- 每个数值按“模型／检查点—数据集与划分—指标—聚合口径—训练条件”核对原表行列及脚注，防止相邻列串位。未报告的数据保留缺失，不凭趋势补值。
- 指标名必须精确：EM、F1、BLEU-1、Q-BLEU-1、ROUGE-L、nDCG 等不能互换；明确平均分包含哪些数据集、指标和权重。必要时用原表分项重算，核对四舍五入，而不是看到 `Avg` 就写成“平均 EM”。
- 不将不同评测集版本／划分放在一组柱图中直接排名；训练数据或实验设置不同的比较说明条件。单项第一、全面领先、某组件带来收益等结论须有相应比较支持。
- 柱长和点位由数值及同一量尺计算，给出轴／刻度和单位。柱图通常从零开始；确需截断时明确标识。散点图显示数值刻度和点的对应标签，不能只有网格与颜色；核对实际计算样式，确保网格、刻度和点位使用同一量尺，避免被旧 CSS 覆盖；切换指标或模型时同步更新范围、标签、数值与图注。
- 区分相对百分比提升和百分点差；不把基于不同配置的消融差值视为单因素因果作用。

## 教学演示与验收

- 玩具向量、相似度、置信分、检索比例和模型输出不是实测结果时，在图或输出旁明确标注，两种语言都可见。原论文没有给出的点坐标或概率，不通过“据某图”暗示为精确原始数据。
- 演示计算要符合已显示的输入和假设：核对正负样本身份、分数方向、公式输出、归一化及边界值；覆盖奖励／阈值的全部分段、饱和上限和零系数，说明文字也须符合平台段与边界。示意滑块表达的是规定假设下的变化，不能宣称重新运行了论文模型或实验。
- 用来源独立确定预期结果，再逐项检查模型／指标／步骤切换后的实际标签、数值、图形与解释。截图检查到图表所在章节，不能用仅包含首屏的截图替代图表目视核对。
- 语法、点击、翻译与布局检查和科学核查分别记录；已有回归脚本即使全部通过，也不能替代原文对照和量尺核对。纯审阅按请求范围交付，未要求的重构或发布不因使用本 skill 自动触发。
