# 化学与材料论文核查（MOF、吸附分离、DFT／MD）

与 [ai-figures.md](ai-figures.md) 并列：后者覆盖 AI／ML 方法图和实验表，本文件覆盖化学、材料与分子模拟页面。只选用与论文实际内容相关的条目。

## 物种与结构身份

- 试剂、配体与连接体逐一对照实验部分的全称和缩写：TMA（偏苯三甲酸，1,2,4-）与 BTC（均苯三甲酸，1,3,5-）、PMIDA 与膦酸基团、酰胺与膦酸配体都不能互换。改名不改数值的错误同样是 P0。
- 节点化学式、连接数、配位数、拓扑与互穿按原文和 SI 核对；“为某材料接枝某基团”要对应到正确的基底材料。
- 元素符号与变量同形时（Ce 浓度与铈、Y、In、K 与平衡常数）就地写清，避免读者误读为元素。

## 单位与定义

- 容量单位：mg/g、mmol/g、mol/m² 不可混用；换算时写出摩尔质量和比表面积。原文自身单位笔误（如摘要把 mg/g 写成 mg/L）按正文与表格采用，并在证据记录说明。
- 分配系数 Kd 的单位（mL/g 与 mL/mg 相差 1000 倍）随表格变化时逐表核对。
- 选择性有多种定义：Kd 之比 SF、对数选择性 log[(qₑ/Cₑ)A ÷ (qₑ/Cₑ)B]、吸附相占比；核对分子分母是哪一对、是否取对数、不要把占比当 SF。
- 去除率、回收率、纯度与富集倍数的分母不同；页面标签按每个进料或产物给出，不复用一个通用标签。

## 条件与数据来源

- 等温线、动力学、pH、选择性、再生实验各有自己的初始浓度、投加量、时间、温度和 pH；图注里“除非另有说明”的默认值不能套到另有说明的实验。
- 实际样品（尾矿、废水、浸出液）的产地与组成按表格题注核对，不把一张表的产地推到其他表。
- 循环稳定性写清循环次数、每次后的测量方式与相对哪一次的保留率。

## 自洽性复算

- 热力学：ΔG = ΔH − TΔS、ΔG = −RT ln K、van’t Hoff 斜率；ΔG 随温度的变化方向应与 ΔH 的符号一致。不一致时保留原表数值并披露，不擅自改值。
- 拟合：Langmuir／Freundlich／PFO／PSO 的参数与 R² 按原表抄录；负的 K_L 或大于 1 的 R² 是原文问题，照录并说明。
- 由公式派生的量（配位数、缺陷数、质量平衡上限、Eyring 时间）用页面给出的输入复算；与原文不符时同上处理。

## 计算与模拟

- DFT：泛函、色散校正、截断能、k 点、电荷与自旋多重度；比较能量要求同一参考点和同一模型尺寸。过渡态旁的数字不是能垒，能垒是相对起点的差；确认教学用的步骤确实是论文讨论的断键步骤。
- MD／增强采样：系综（NVT／NPT／NVE）、温度、时长、步长、偏置方法；偏置轨迹上的事件时间不是真实等待时间。
- 机器学习势与性质模型：训练、验证、测试划分的范围与误差口径分开写；同一架构在不同划分上重新训练，不能说成“同一个模型”。
- 振动谱、PXRD 峰位等谱学归属按原文分区逐段核对，不把整段频率区间概括为单一运动类型。

## 综述与无 SI 的论文

- 综述只核对综述本身的表述和表格；被引原始研究未独立读完时写明。
- 原文没有 SI 时在证据记录写“无 SI”，并说明哪些主张只能对照正文。
