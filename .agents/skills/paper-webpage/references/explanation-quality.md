# 论文讲解质量：验收方法与适用示例

科学内容新建、深度精修及试读反馈修订时使用。本标准检验读者能否重建论文的论证，不按篇幅、控件数量或技术测试数量评分。纯样式修改不触发整篇科学重审。

## 页面结构与交互

采用适合该论文的篇幅和章节，讲解主线通常是：

1. **核心思想**：一句话贡献、关键图示，以及读完应理解的问题。
2. **背景问题**：已有方法、缺口、必要术语和适用场景。
3. **方法机制**：输入、步骤、中间状态与输出，逐层解释公式及假设。
4. **实验证据**：与结论对应的数据、基线、条件、消融和有效范围。
5. **局限与联系**：证据边界、未解决问题、与相关工作的联系和研究启发。

- 用概要、可展开细节或学习深度切换组织层次，避免把全部专业内容堆在首屏；按材料选用，不强制每页具有同一种控件。
- 设计能帮助理解的交互，如算法分步、结构/位点选择、条件或指标对比、明确假设下的教学计算。控件必须改变对应图示或解释，并显示当前状态；按需提供重置。
- 图表注明量、单位、刻度、条件和来源；数据与标签共同切换。测量数据、示意坐标和模型预测使用明确标识。
- 实验数值须逐行逐列对应原表的模型、数据划分、指标及聚合方式；数字正确但列名或“平均分”含义错误同样需要修正。条长、点位和颜色图例由同一份数据与明确量尺生成，避免手调图形夸大差异；教学数值及计算假设在对应图旁说明。
- 多对象或多阶段的密集说明优先用关系图、流程或原图配对重组。可使用原文图片和适当裁切，保留必要坐标、图例、对照、出处和完整图入口；教学示意与真实证据就地分清。

## 读者与阅读路径

先确定知识依赖。本项目默认按有高中知识、尚不熟悉论文专业领域的读者编写；用户明确指定其他基础时沿用会话。只有不同受众会实质改变讲解且信息不足时，询问这一项关键问题，同时继续不依赖答案的工作。

提供直觉、机制和研究细节三个层次，可用连续阅读、渐进展开或已有深度切换实现，不要求新增三档控件。直觉层必须独立给出研究问题、核心依据及必要限制；机制层解释为什么和如何；研究层补充条件、推导、替代解释及复现细节。关键限制不能藏到最深层。

### 高中知识如何接到研究问题

- 从具体对象开始：例如先解释连接点、分子连接体、孔和吸附，再用 MOF、位点、容量推进推理。数据库编号先说明不是化学式。定义的难度不能依赖另一个尚未解释的术语。
- 仪器／算法讲清“放进去什么→做什么→输出什么→怎样解释”。GCMC 展开英文仍不够，需要说明随机尝试、概率取舍和求平均；HPLC／ICP-MS 则说明分离识别或元素计数、校准及检测对象。
- 单位先回答“什么除以什么”。VPOV 是几何孔体积比，STP 是气体体积的参考条件，BET 是每克回收固体的气体可达表面积；三者不直接表示完整框架的质量比例。未核实的单位约定不能用于新换算。
- 用比例图或一个注明假设的可复算算例搭桥；实测值、按实测数值换算、虚构教学数值须分别标明。对数、归一化、拟合等首次参与推理时给直觉与用途，再在深层给公式。
- 重排先后顺序和图文关系，不只加长术语段。高级配置可以保留在深层，直觉层仍应说明关键条件与不能推出的结论。留给读者的任务必须能从默认层或清楚指引的进阶层找到依据。

## 可验证的内容要求

1. **问题与贡献**：读者能说出研究想解决什么、原有做法缺什么、本文增加了什么能力或证据。综述解释其组织视角与争议，不伪装成单项新实验。
2. **背景与术语**：先解释依赖再使用结论；仪器／算法／指标要说明输入、处理和输出。不要用“仪器证明结构稳定”“模型效果很好”等未定义表述推进论证。术语就近解释或复用已有可访问解释，避免把每个词都做成弹窗。
3. **推理链**：核心机制或方法连成“起点 → 操作／假设 → 可观测或可计算结果 → 允许的判断”。每个关键步骤交代目的、产物及缺少该步会产生的歧义。相关性、拟合或模型输出不自动等于因果机制或实验观察。
4. **实验／计算设计**：解释参照、对照、分样、处理及验证为何存在。实验图区分同批、同一物理样品、平行实验及破坏性参照；计算图区分训练／验证／测试、学习到的量与外部验证。箭头必须对应真实依赖，不能为排版把平行步骤串联。
5. **图表阅读**：关键图旁解释坐标、量与单位、尺度、条件、对照、先比较哪两组、看到什么及不能推出什么。表格同样检查行列含义和分母。归一化、断轴、误差、未检出与缺测就地说明，不从线条外观虚构精确值。
6. **定量解释**：关键公式定义符号、单位、分母、假设、适用条件与用途；需要时用一个可复算的例子。不同分母的百分比不能相加，容量不能自动充当选择性，预测分数不能自动充当实验成功率。没有核心公式的文章不为模板硬加公式。
7. **证据身份**：明确区分原文观察／计算结果、作者解释、讲解者推断、教学假设或演算。关键结论链接到具体图表、章节或 SI；仅在页末列论文不够。限定词和证据强度必须中英一致。
8. **限制与外推**：说明限制来自哪里、影响什么判断、需要什么证据补足。材料批次、介质、时长、训练分布、标签定义或评价协议按论文类型选用，不照搬其他样板的限制。
9. **有效图示与交互**：密集文字若同时混合多个对象、阶段或证据，应改用关系图、步骤图、图文配对或适量分段。图示要减少读者自行组织信息的负担。交互要回答一个具体问题，操作改变相关图示／比较／解释，反馈说明原因。静态图已足够时不添加控件；需要验证迁移推理时加入适量应用题，不强制固定数量。
10. **阅读与可用性**：双语覆盖正文、图内说明、公式解释、反馈、图注和无障碍名称；保持选择、展开与焦点。窄屏重排不得改变科学依赖。检查实际渲染文本，不能只检查源码中存在解释。

## 措辞忠实与原文矛盾

全站审计中最常见的错误不是数字抄错，而是转述时改变了证据强度或适用范围。逐句对照以下各项：

- **保留作者的保留语气**：原文写 “suggests”“may”“we attribute this to” 时，中英文都写成推测或作者归因，不改成事实陈述。作者主张与讲解者的附加限制分开写，例如“作者称其无偏；本页认为……需附条件”。
- **不放宽也不收窄条件**：“高温水”不能写成“沸水”，“全部 8 个游戏”不能写成“8 个游戏中有收益”，“低湿度下”不能写成“湿烟气中”。中英文的限定词须一致，常见漏洞是只有一种语言保留了“全部”“仅在”等词。
- **不合并不同来源的数值**：两个结果来自不同轮次、检查点、表格列或参数组时分别标明，不并列成同一组结论。同一组数据不混用图中读数和正文数值。
- **原文自相矛盾**：正文与表、表与图、图注与正文不一致时，默认采用表格或原图标注（图中数值以高分辨率复读为准），在页面就地说明另一处的写法，并记入 `sources.md`。不擅自“修正”原文数值。
- **图中读数要可复查**：从图上读出的值记录图号、面板和渲染分辨率；“已对照原图”必须在能看清标签的分辨率下完成。
- **显示逻辑不制造限定**：`>`、`≈`、“约”等限定词来自原文，不由格式化代码按阈值自动添加。
- **教学映射也要符合论文条件**：滑块阈值、分段和状态名称须与论文报告的条件一致；虚构的百分比或分数要标为示意，不能像测量数据那样显示。
- **图表选择与高亮**：只展示部分基线时在标题或图注写“节选”；高亮依据数值（如最高值）而不是数组位置。不能复现的聚合值（未说明加权的 Avg.）标为“论文报告值”。

## 原图、重绘与教学图

优先使用能直接支撑判断的原论文图片，核对来源及使用许可，保留署名、图号与必要上下文。可裁取相关面板并提供完整图链接；裁切不得隐去改变解释的坐标、图例、对照、比例尺或误差。原图英文标签可保留，但旁边提供完整双语读图说明，不把原标签识别失败当成翻译。

原图用于展示证据，教学图用于解释原理或方法关系，二者可并置。不要为视觉统一重画原始科学数据，也不要用“教学示意”掩盖错误的拓扑或方法箭头。教学坐标、假设参数及非实测曲线须在图旁标识；避免让假设图与实测图共用含混的标题。

真实坐标模型按实际需要使用，不是每篇必备。采用 CSD、作者 CIF 或其他数据库时记录条目、版本、坐标来源、客体／氢／无序处理、晶胞与有限显示边界；优先保留来源中的连接，不用外观臆造键。核对坐标和连接，尤其是金属配位与跨晶胞连接。若作尺寸比较，使用共同尺度或清楚标尺，缩放后同步更新。显示半径不是原子真实边界，可旋转模型也不能独立证明孔可达性、稳定性或吸附量。源结构与作者清洗过的计算输入有差异时就地说明；没有可信坐标时使用原图，不编造结构。

### 综述的特殊证据关系

把“被综述的研究→各自条件与表征→综述的分类或解释”画清楚。保留样品、温度、介质、时间、再生和测量方法的差异；不同文献不自动构成同批样品的时间序列或可直接排名的实验。综述自己的类别、证据置信度和真实热力学量须分开。SI 中的反例要解释适用范围，不能删去后只保留积极结论。没有逐篇核对被引原文时，明确当前证据来自综述及其 SI。验收任务可要求读者选出还需核对的条件，而非背诵“最稳定材料”。

## 试读反馈闭环

逐项记录原句／页面位置、原因、对应修改及一个能检验改善的阅读任务。原因可并列：背景知识缺失、术语不清、证据链断裂、图示不充分、阅读结构问题；不要把所有困难都处理成追加一段定义。

区分三种结论：

- **科学核验**：陈述、图示、公式和数值与哪些原始证据一致，哪些仍未证实。
- **讲解审查**：问题是否有对应解释，读者能否按预期路径找到必要依据；自审只证明覆盖与可追溯性，真人理解效果另记。
- **技术检查**：实际运行的视口、语言、状态、异常和键盘检查；技术通过不证明讲解充分，也不能否定真人报告的跳步。

原反馈留空不视为对现有模块的认可。修订保留有效内容，可重组／展开，避免纯增加篇幅。用户限定本地样板时保持本地；固化标准不等于授权批量改页或发布。

## 实验诊断示例：UiO-66 在缓冲液中

参考本仓库 `papers/uio66-buffer-stability/` 及其证据记录。以下用于说明规则的落地方式，不要求其他论文复用同样版式或数字。

- **不清楚的信号**：“4 小时后仪器仍能辨认晶体特征。”改为命名 X 射线衍射仪／PXRD，用射线源→粉末→探测器→角度—强度曲线解释测量，再对照原图4的黑色原样和红色0.01 M PB曲线。保留归一化／平移／10°放大区／Mylar星号限制。验收问题：为什么这些残余峰不能直接给出完整框架剩余百分比？
- **缺少目的的方法清单**：“同一份材料，追踪两类组分。”改为同批分样；分开画破坏性总量参照、玻璃瓶中的连接体实验、塑料器皿中的平行锆实验及回收固体表征。依据为 Experimental 和 SI S3，不能画成 HPLC→ICP-MS 串联检测。验收问题：为什么两种组分各有自己的100%分母，为什么锆低读数不能替代连接体测量？
- **密集方法段**：将 PXRD／N₂吸附-BET／SEM 与 HPLC／ICP-MS 按“回收固体／过滤液体”分支，分别标出测量输出与盲区。此图解释证据互补，不是物种分配比例。
- **实际显示失败**：字面 `<LOD` 被浏览器当成标签，导致定义或题干被吞掉。转义为 `&lt;LOD` 或用安全文本绑定，并检查完整可见句子和数值；仅检索某个精确未知标签名可能漏掉带逗号的变体。

## 计算筛选示例：水稳定、高吸水 MOF 的机器学习发现

参考 `papers/water-stable-mof-discovery/`、其 `sources.md` 和 `reports/discovery-quality-transfer/`。这是从实验诊断向计算筛选的实际迁移，不能把它的技术验收当成真人理解测试。

- **替换证据对象**：将实验样板的固体／液体证据互补，改为文献稳定性标签→既有分类器、GCMC吸附标签→新回归器两条训练来源；随后另画筛选新结构的顺序。验收问题：刚性吸附计算为何不能证明框架耐水解？
- **把方法列表变成可操作的比较**：用明确虚构的母体×修饰组矩阵演示随机、按官能团、按母体留出。切换同时改变训练／测试身份与解释，旁边保留论文原始测试误差。九格示例不冒充原数据量或真实划分比例。验收问题：要筛选训练中从未见过的母体，该参考哪个测试，为什么？
- **原图与指标互相支持**：MAE先解释符号、单位与一个可复算的教学例子，再用原图5说明“True”来自GCMC、对角线表示一致、着色表示点密度。ZULNAX低估是计算观察，缺少相关训练化学是作者的可能解释；二者不合并成已证实因果。
- **按类型保留限制**：把仪器盲区换成刚性框架、标签定义、数据分组、分布外适用性和版本差异。保留模拟／预测／实验的区别；不机械加入固液平衡、检测限或真实时间滑块。

## 验证跨论文迁移

选一篇在研究问题、方法或证据形态上与已有样板明显不同且资料可核对的论文。先记录选择理由与原页缺口，再实际应用标准；不能仅列一篇候选或跑静态检查就称迁移成功。

记录哪些要求直接适用、哪些需按论文类型改写、哪些不适用。以页面中的具体实现和读者可回答的问题说明迁移结果。化学实验的“固液两侧”可迁移为机器学习的“标签／预测／外部验证”证据区分，但不能照搬图形或暗示它们是同一种实验。迁移结果仍分别报告科学、讲解和技术状态；真实学习效果保留待试读。

## 综述迁移示例：MOF 水稳定性与吸附

参考 `papers/water-stability-review/`、其 `sources.md` 和 `reports/standards-high-school-transfer/`。这个示例检验的是异质证据的讲解，不能把它复制成所有综述通用的实验故事。

- **先解释证据如何产生**：原始研究的样品／条件／测量 → 综述和 SI 的记录 → 耐受类别与证据置信度。置信度是证据支持程度，不是“这个材料有多大概率成功”。验收问题：为何 La-BTB 可有较耐受的历史类别却只有低置信度？
- **保留矛盾并教会比较**：把 MIL-100(Fe) 的“一周沸水后 PXRD/BET 未变”（SI S5）和“两天液水后 PXRD 保留、BET 大部分损失”（SI S6）并排列出。未给出的温度和损失百分数写明缺口，不补成数字；不同研究不能连接为时间曲线。验收问题：为什么不能据此说沸水修复了材料，下一步应比较什么？
- **先读图再读公式**：原图28分步解释自由能纵轴、非时间横轴、相同终点差与不同障碍；G、Δ、‡和适用条件在推理前解释。验收问题：为何相同终点不代表相同速度，且此图不能给出材料寿命？
- **证据层次可迁移，具体控制不照搬**：实验观察替换为“SI 所记各研究观察”；作者解释替换为“综述提出的可能差异来源”；讲解者判断是“应核对原始方案”，不是已证明的冲突原因。没有独立读完被引论文时明确阅读范围。
- **高中基础示例**：UiO-66 页先定义材料、节点和连接体，再解释仪器；HPLC／ICP-MS从输入经操作到校准输出，百分数先解释分母，再用 `(0.08 ÷ 335) × 100% ≈ 0.024%` 演示。验收问题：99%连接体释放为何不是99%整份材料消失，两个组分的百分数为何不能相加？

这些例子已完成本地科学核对和浏览器检查；是否真正降低理解障碍仍需读者试读，不能把技术检查的状态数量写成教学效果。
