# 页面实现与统一视觉

先读取[共享阅读系统说明](../../../../papers/README.md#shared-reading-system)、[共享样式](../../../../assets/paper.css)与[共享控制器](../../../../assets/paper.js)，以当前实现为准。参考 [RAG 页面](../../../../papers/rag/index.html) 的渐进讲解和 [Ln 局部配位页面](../../../../papers/ln-local-coordination/index.html) 的证据关联方式。在下述共享视觉规范内，根据论文设计章节、图形与交互布局，不机械复用同一套卡片。生成页先按 [site-integration.md](site-integration.md#生成页与编辑源) 找到编辑源。

## 页面框架

- 默认使用原生 HTML、共享本地 CSS／JavaScript、页面内的专属样式与逻辑，以及内联 SVG 或 MathML。现有项目不需要为单页引入框架、构建系统或运行时 CDN。必要的原图等放在页面旁的 `assets/` 并使用相对链接。
- 对 `papers/<slug>/index.html`，在本页样式之后加载 `../../assets/paper.css`，在本页脚本之前加载 `../../assets/paper.js`；`body` 设置 `class="atlas-paper"` 和 `data-paper="<slug>"`。共享附加样式（`bibliography.css`、`paper-lesson.css`）可在 `paper.css` 之后；本页的组件附加样式（如 Ln 页的 `annotations.css`）也可在其后，但不得改写共享 `.atlas-*` 组件、`html`、`body` 或 `:root`，否则静态检查会警告。论文页另按 [site-integration.md](site-integration.md#署名单位与论文日期) 加载署名资源。使用其他目录层级时按实际位置调整相对路径。
- 页面状态、内容及渲染函数就绪后调用 `AtlasPaper.init({shortTitle, title: {zh, en}, sections: [{id, zh, en}], depth, legacyHeader, allowBoth, onLanguageChange})`。`sections` 对应真实章节 ID；`depth` 是可选的现有深度控件 DOM，`legacyHeader` 是迁移时要移除的旧顶栏 DOM，无则传 `null`；`allowBoth` 默认设为 `false`，完整实现中英对照的页面可设为 `true`。
- `shortTitle` 是单一字符串，在两种语言的顶栏中原样显示，必须语言中立（如 `CALF-20`、`MOF · H₂O`），不能写中文或只适用一种语言的说明词。
- 控制器会移动深度控件并生成公共顶栏、导航和进度；`onLanguageChange(lang)` 在初始化时同步调用，随后每次切换都会调用，因此回调所需状态须提前初始化，不能依赖本次初始化尚未返回的控制器变量。返回对象提供 `lang`、`setLanguage(lang)` 和 `refresh()`。迁移旧页时清理依赖旧导航、语言按钮或进度元素的事件，避免重复控件与已移除节点引用；共享语言按钮使用 `data-atlas-lang`，避免与本页的 `data-lang` 事件混用。
- 页面支持静态托管；核心内容和交互尽量不依赖网络。使用本地资源时避免从 `file://` 读取需要跨源请求的数据；通过本地 HTTP 服务检查与部署环境一致的行为。
- 设置 UTF-8、`title`、`html lang`、viewport、章节锚点、论文来源及返回站点链接。主内容使用语义化结构，SVG 规则限定作用范围，避免污染公式、图标或引用插件注入的元素。正文中的字面 `<`（如 `<LOD`）必须转义为 `&lt;`，否则浏览器会把后续文字吞成未知标签。
- 图片阅读器须显示加载与失败状态，保证最终图片、图号、图注和选中按钮对应同一选择；新图未就绪时避免旧图冒充当前所选图。连续切图时忽略过期加载结果，防止旧请求覆盖新选择；预加载可用于改善体验，但不能替代状态处理。
- 窄屏下重排布局；宽表格和公式可在容器内滚动。使用真实按钮、可见焦点、输入标签、可读对比度，并尊重减少动态效果的系统偏好。

## 中英双语

- 中英切换覆盖正文、导航、图内文字、工具提示、交互反馈、页面标题和无障碍标签；中文模式中的说明性英文标签也应本地化。模型／数据集名、公式符号、原论文标题、作者名和正式引用可保留原文。来源定位中的章节、公式、图表编号和原文档标题可保留；“实验与消融”“理论假设”等说明性词语需本地化。
- 双语检索等教学例子需要保留中文源句时，标记 `data-language-example="zh"`、`lang="zh-CN"`，并提供英文释义。
- 语言初始化、URL、存储和跨页链接交给共享控制器：有效 `?lang=` 优先于 `atlas-lang`，再回退中文；仅保存 `zh`／`en`，`both` 可在支持对照的页面 URL 中使用。存储不可用时仍可切换，更新语言时保留其他参数和锚点。
- 静态内容使用明确的翻译键、稳定的精确文本绑定或成对双语模板；动态说明根据当前实验状态输出。避免可逆的全页字符串替换或模糊子串替换。SVG 文字、`alt`、`title`、`aria-label` 等按当前语言单独更新。
- 语言和深度切换保留滑块值、步骤／图表／节点选择、测验结果、展开项、滚动位置与键盘焦点。优先更新文字和输出容器，避免为语言切换重建整个正文或输入控件。默认中文、显式英文链接和刷新后的语言选择均需可用。

## 统一视觉

新建和更新讲解页默认沿用 Research Atlas 首页及现有讲解页的深蓝／青色风格。

- **配色**：背景 `#07111f`、面板 `#101e31`／`#15263b`、正文 `#f4f7fb`、次要文字 `#a8b4c7`、边框 `#293a50`、主强调 `#7de3ff`。优先引用共享 CSS 变量；青绿、淡绿、橙、粉、紫等辅助色用于图表分类、证据类型或提示，并保持含义一致。
- **排版**：统一系统无衬线字体、1180px 正文最大宽度、20px 通用面板圆角及共享标题、章节间距。桌面左右留白 24px，手机 18px；实际字号、断点和间距由共享 CSS 管理。长中英文标题要自然换行，避免单字孤行。
- **导航**：使用共享两行吸顶栏；第一行是返回 Atlas、论文简称、可选阅读深度和语言，第二行是可横向滚动的章节导航，并提供当前章节高亮、阅读进度和跳至正文链接。手机端控件自动换行，章节入口保持可用。锚点偏移使用共享 `scroll-margin-top`，不要叠加全局 `html scroll-padding-top`，以免吸顶语言按钮聚焦时意外滚动。
- **层次与控件**：保留各篇独有的图示、实验模块与深度含义。有三档深度时使用“直觉／机制／研究”（Intuition／Mechanism／Research）；已有“全景”（All）或详情展开按内容保留，不为统一外观强加深度控件。
- **局部图形**：局部 CSS 负责论文专属结构，选择器限定在本页或图示容器内；共享 `.atlas-*` 导航组件由公共资源维护。检查内联样式和 JavaScript 生成的颜色，避免深色页面残留浅底深字或低对比文字。原论文图像保留原色，必要时放在白底图框并配置清晰的图注；保留引用处注入图标的尺寸限制。
