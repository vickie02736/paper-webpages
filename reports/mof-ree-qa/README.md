# MOF / REE verification evidence

The 28 source ledgers in `papers/<slug>/sources.md` record the complete article/SI coverage, claims, scientific output states, numerical checks and source discrepancies. Per-page JSON and text logs here record scientific/browser checks across 1440, 768 and 390 px in Chinese and English. Representative screenshots were visually inspected throughout the page reviews.

This directory retains two representative scientific screenshots per new page (56 total). The full 876-image scientific QA run remains in the local archive `/tmp/mof-ree-qa-archive`; `screenshot-inventory.json` records filenames and hashes. Temporary archives are not durable repository assets. Copyrighted article/SI originals remain outside the repository.

Candidate-validation and candidate-bibliography logs document checks before catalogue integration. Production metadata, catalogue, taxonomy and all-explainer regression results are in `final-*.log`; these run against the integrated catalogue and the production metadata bundle without candidate overrides. Final regression screenshots remain in `/tmp/mof-ree-final-qa`, with a few retained catalogue examples here.
