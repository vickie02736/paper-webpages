理解 verl 背后的算法

12 篇论文精读与 3 个文档专题。从目标函数、更新信号和实验口径理解方法，再阅读实现附注。

选择一页开始阅读

  • 论文精读

    PPO

    对已经获益的动作，停止奖励过大的概率变化。裁剪改变优化目标，却不把整个策略锁在一个硬边界内。

  • 论文精读

    GRPO

    从同一问题的多个答案中估计相对优势，省去单独的价值网络；组内归一化也会改变不同问题的权重。

  • 论文精读

    DAPO

    把裁剪、有效问题采样、token 权重和超长奖励一起纳入设计，解决长链推理中的探索与训练稳定性问题。

  • 论文精读

    SPIN

    反复区分固定的人类示范与当前模型生成的答案，持续利用已有 SFT 数据，而不必每轮购买新的偏好标注。

  • 论文精读

    SPPO

    直接建模答案之间的胜率，把偏好对齐写成常和博弈，通过自博弈逼近不容易被对手利用的策略。

  • 论文精读

    Entropy Mechanism

    策略越来越确信已有答案时，训练可能失去探索空间。论文从概率与更新的协方差解释熵变化，并选择性约束高协方差 token。

  • 论文精读

    OPO

    严格使用当前策略采样，再以梯度方差为目标选择奖励基线。实用版本用答案长度近似梯度能量权重。

  • 文档专题

    Algorithm Baselines

    一个分数必须连同模型、数据集、指标、后端和评测协议一起阅读。这里整理 verl 的公开运行记录，不把异构配置排成算法排行榜。

  • 论文精读

    GPG

    保留直接策略梯度，去掉组内标准差缩放，并按有效样本比例校正梯度幅度。简单目标仍需要认真处理批次统计。

  • 文档专题

    Rollout Correction

    把真实采样分布、PPO 的旧策略锚点和当前策略分开，分别处理数据分布偏移与优化更新。

  • 文档专题

    Rollout Correction Math

    重要性采样的核心是把一个分布下的期望改写到另一个分布；token、前缀与整条序列的权重对应不同估计问题。

  • 论文精读

    OTB

    用生成过程累计的梯度能量估计每个位置的奖励基线，减少长序列中的方差，并避免把 padding 当作真实样本。

  • 论文精读

    DPPO

    同样的概率比，在低概率和高概率 token 上代表不同的分布变化。DPPO 使用散度近似定义更新掩码。

  • 论文精读

    OPD / GKD

    学生先生成自己的轨迹，教师再对这些前缀给出分布反馈。训练时见到的状态因而更接近学生推理时真正遇到的状态。

  • 论文精读

    DRO

    从提示、回答、标量反馈三元组出发，以正则化最优策略的关系构造平方目标；在实现中必须保留 soft advantage 的含义。
