# LanM protein process

This page explains Dong et al., “Bridging Hydrometallurgy and Biochemistry: A Protein-Based Process for Recovery and Separation of Rare Earth Elements,” *ACS Central Science* 7 (2021), 1798–1808. It covers LanM immobilisation on agarose, low-pH capture, selective elution and the Powder River Basin fly-ash leachate demonstration.
