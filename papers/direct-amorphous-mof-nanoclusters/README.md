# 从纳米簇直接合成非晶 MOF

双语讲解 Baun 等发表于 *Nature Communications*（2026）的研究。页面区分非晶 MOF 与玻璃态 MOF，解释 NC、OP、SW 三种路线、PDF/TGA/XAS 证据链、缺陷与相干长度，以及“局部像晶体、整体不是某个晶体”的结构边界。

来源与阅读记录见 [sources.md](sources.md)。

## 交互阅读

- 所有图形均标明证据与示意边界；不使用类比。
