# MOFTransformer · 多模态预训练与通用迁移

Interactive explainer for Kang et al., “A multi-modal pre-training transformer for universal transfer learning in metal–organic frameworks”, *Nature Machine Intelligence* 5, 309–318 (2023).

- Paper: https://doi.org/10.1038/s42256-023-00628-2
- Explainer: https://vickie02736.github.io/paper-webpages/papers/moftransformer/
- Scope: local atom-graph and global energy-grid inputs, multi-task pre-training, transfer to adsorption/diffusion/electronic/text-mined properties, and attention-based interpretation.

The page uses the shared Research Atlas reading system. It is bilingual (Chinese/English), includes an interactive modality walkthrough, pre-training-task selector, Table 1 metric explorer, attention comparison, and evidence-boundary notes. All reported values are traced in [`sources.md`](sources.md).
