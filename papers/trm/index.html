TRM：让长推理链的更新更可靠

01

为什么长回答更难稳定

语言模型每次给“下一个 token”分配概率；token 是一段文字的编码单位，不一定是一个汉字或单词。一次 rollout 就是按这些概率逐步生成一条回答。强化学习根据回答的奖励，提高好回答的生成倾向。

但生成回答的引擎与训练模型可能给出不同概率。精度、算子、专家路由或参数滞后都会造成偏移。前面的选择改变后续看到的上下文，因此长回答中的偏移不能只看成互不相关的单步误差。

TRM 的操作很直接：逐位置比较两个分布，一旦某个位置越过阈值，整条回答在本次更新中的贡献归零。它控制的是“哪些轨迹用于估计更新”，并未把模型本身投影回某个安全区域。

关键限制：在已采样回答上通过筛选，不等于所有可能上下文都满足理论条件。TRM v5 明确区分这两件事；高通过率也不保证被掩码目标接近原目标。

02

从 token 检查到序列掩码

  1. 采样并保存概率：生成回答 y，同时记录采样策略 πroll 的输出。
  2. 同一前缀重新打分：训练策略 πθ 对每个位置的全部候选 token 计算概率。
  3. 先按位置计算 KL，再取有效位置的最大值，与 δ 比较。
  4. 整条序列保留或置零：按原批次 N 条回答归一化，再更新模型。
ρₜ = πθ(yₜ | cₜ) / πroll(yₜ | cₜ)
Dₜ = Σᵥ πroll(v | cₜ) log[πroll(v | cₜ) / πθ(v | cₜ)]
Mᵢ = 1[maxₜ Dᵢₜ ≤ δ]
Lmasked = (1/N) Σᵢ Mᵢ Aᵢ Σₜ ρᵢₜ
∇θ Lmasked ≈ (1/N) Σᵢ Mᵢ Aᵢ Σₜ ρᵢₜ ∇θ log πθ(yᵢₜ | cᵢₜ)

cₜ 是提示词和此前生成内容；yₜ 是实际选中的 token；v 遍历整个词表。ρ 的分母必须是实际采样策略。KL 的方向则是 πroll 到 πθ，使用自然对数，单位为 nat；它衡量整个候选分布的变化，不能用某个 token 的概率差替代。

Aᵢ=Rᵢ−b 是相对基线 b 的奖励优势。Mᵢ 取 0 或 1，反向传播时视为常量；上式表示论文采用的停止梯度更新。N 是原始批次大小，拒绝后不改成“被接受条数”。padding 不是生成位置，必须排除在最大值、求和和长度之外。

标准 PPO 的 min 裁剪依优势正负而变，并不是双侧都硬置零。例如 A<0 且 ρ 很大时，未裁剪分支仍有梯度。TRM 则把同一回答的所有有效位置一起掩码；代价是连同其中较可靠的位置也一起丢弃。

若无法保存全词表 logits，附录 E 提议：用 k₂(ρ)=½(log ρ)² 检查最大异常，用 k₃(ρ)=ρ−1−log ρ 检查平均偏移。在完整支持条件下，k₃ 对采样分布取期望等于上述 KL；单次样本值不等于精确 KL，k₂ 也不是无偏 KL 估计。

03

观察掩码，而不是猜测

一处偏移，整条回答会怎样？

教学计算 · 二元概率与参数换算，不运行模型训练。

此处每个位置只有两个候选项，采样分布固定为 [0.5, 0.5]，实际选中第一个候选项。第一条回答的训练概率为 [0.52, 0.54, q, 0.48, 0.51, 0.53]；第二条每个位置均为 0.52、优势固定为 −0.5。两条回答同长，原批次 N=2。

试一试：保持 q=0.9、δ=0.05，把有效长度从 6 改成 2。为什么整条序列从拒绝变成接受？

展开推理

异常发生在第 3 个位置。长度为 2 时它属于 padding，不参与最大值与更新求和。剩余最大 KL 约 0.00321，小于 0.05。不能让 padding 的概率改变有效回答的掩码。

04

理论能保证到哪一步

论文把真实奖励变化与代理目标之间的差异写成“上下文分布漂移 × 后续更新影响”。KL 链式法则与 Pinsker 不等式给出一种控制上下文漂移的办法，TV 耦合给出另一种；综合多条独立上界可得到更紧的界。

TV（总变差距离）是两个离散概率分布逐项差的绝对值之和的一半，范围为 0 到 1。它可以理解为使两个分布一致至少需要重新分配多少概率质量。KL 为 0 表示两个分布一致，但一般没有 1 这个上限。

L′ = Eroll[R Σₜ(ρₜ − 1)]
|J(πθ) − J(πroll) − L′| ≤ B
Bclassical = T(T−1)δ
BPM = 4 min(1, √(δ/2)) Σₜ₌₁ᵀ min(1, √((t−1)δ/2))

J 是期望序列奖励，R∈[0,1]；T 为固定或按约定补齐的理论时域。δ 在这里约束所有可达上下文的最大 KL，不能直接拿一批样本的最大值代替。L′ 是中心化的奖励形式，满足 πθ=πroll 时 L′=0。对于固定 b，未掩码的优势形式 L 与 L′ 相差 T(Jroll−b)，梯度相同而数值未必相同。

长序列如何放大误差上界？

教学计算 · 二元概率与参数换算，不运行模型训练。

演示计算式 (12) 的带上限精确求和，以及经典 KL 上界；没有模拟奖励，也没有声称这就是全部方法的最小界 B*。即使上界变小，也还要检查 L′ 是否超过它，才能按相应定理判断改进。

研究细节：Mixed 界额外利用整条轨迹的 KL 或 TV；Adaptive 界保留各位置期望 TV，并按剩余长度选择较紧的路线。表 1 在 T=4096、δ=10⁻⁴、ε=0.005、序列 KL=0.01、序列 TV=0.05 时，将经典 KL 界约 1677 降至统一界 ≤4.1。这是理论参数代入，不是 AIME 提升幅度。

在全局条件成立时，所有轨迹均通过，M≡1，掩码目标才与原目标相同。若拒绝真实发生，附录 G 的无全局条件界改用奖励形式 L′masked，并付出接受区域误差 BA、拒绝率 r 和序列 TV 的代价；它不能直接证明算法的停止梯度优势更新必然改进。

代价、长度偏差与版本边界

长度无关的阈值不等于长度无偏。只要每个位置有小概率 p 违规，在独立同分布的教学假设下，通过率就是 (1−p)ᵀ。长推理链有更多触发拒绝的机会，可能被系统性低估。

附录 F 提出加权归一化的 LN-TRM 和平均 |ρ−1| 的 SER 变体；这些改变了筛选准则与保证条件，不应与 Max-TRM 混称，也没有在图 1–3 中给出对应消融。保存完整词表 logits 的存储、传输与计算代价，也不能被“无额外模型推理”一句话抹去。

与站内 Rollout 校正专题的关系：重要性采样修正概率比，TRM 决定舍弃哪些轨迹，两者解决不同环节。既有专题引用早期 v1；本页依据 v5，特别保留新版对全局前提和掩码目标的限定。
