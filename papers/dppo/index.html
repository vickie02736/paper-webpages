DPPO：从概率比走向散度

同样的概率比，在低概率和高概率 token 上代表不同的分布变化。DPPO 使用散度近似定义更新掩码。

Rethinking the Trust Region in LLM Reinforcement Learning · 2602.04879v3

原论文 ↗人工智能与计算
01

研究问题

把一个动作的概率从 1% 提到 2%，概率比翻倍，但只移动了 1 个百分点。把 80% 降到 60%，比例变化较小，却移动了 20 个百分点。散度试图衡量整个分布改变多少；二分类近似把“选中 token”和“所有其他 token”分成两类。

相对变化与绝对分布变化并不相同。一个概率从 0.001 变成 0.002，比例翻倍但质量变化很小；高概率动作的较小比例变化却可能对应较大质量移动。论文在有限时域语言模型设置中重新推导信赖域界。

02

方法怎样工作

  1. 完整词表散度计算代价高。Binary 近似把采样 token 与其余词表合并成两类；Top-K 近似保留更多概率信息。这些粗粒化散度是完整散度的下界，不是精确的完整词表度量。
  2. 掩码会结合优势方向：超出散度阈值且更新继续沿有利方向远离采样策略 μ 时抑制该项；回到锚点方向的更新仍允许。这里 DPPO 指 Divergence PPO，不是名称相近的 Diffusion Policy Optimization。

03

从符号到目标

p 为采样（rollout）策略 μ 对已采样 token 的概率，q 为当前训练策略 π 的概率；KL 方向为 μ 到 π。论文要求信赖域以原始采样策略 μ 为锚点，而不是重新计算的旧训练策略概率（§5.2 要点 2；附录 E）。演示将概率限制在 (0,1) 内避免 log(0)，同时显示 r=q/p、Binary-TV、Binary-KL 和更新掩码；阈值不同量纲，不能直接当作相同强度。

DTV = |p−q|
DKL = p log(p/q) + (1−p) log((1−p)/(1−q))
mask = 1 if D≤δ or A(q−p)≤0; otherwise 0

理论界、散度近似和实际动态 mask 是三个层次。散度下界超过阈值可提示真实变化较大；下界较小却不能证明完整策略的散度同样小。

06

适用条件与局限

近似散度可能漏掉词表其他部分的变化，阈值也需要具体任务验证。实验覆盖不等于所有模型和任务的普适保证；理论证明中的条件应和神经网络实现的近似保持区分。

p=0.05、q=0.1、A>0、TV 阈值 0.1 时，DPPO 与 ε=0.2 的 PPO 是否都抑制该项？

展开推理

PPO 的比率为 2，超过 1.2，进入平台；Binary-TV=|0.05−0.1|=0.05，小于 0.1，DPPO 仍允许该项。此例只比较指定阈值，不说明所有设置下谁更好。
