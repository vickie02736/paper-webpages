# 用有机熔剂重构玻璃态 MOF

双语讲解 Weiß 等发表于 *Nature Materials*（2026）的研究。页面解释 1,10-菲咯啉如何同时降低玻璃化温度、介导配体交换、改变 Co 节点连接度，并讨论孔隙、力学和磁性的取舍。

来源与阅读记录见 [sources.md](sources.md)。
