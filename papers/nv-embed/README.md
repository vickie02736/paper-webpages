# NV-Embed — Improved Techniques for Training LLMs as Generalist Embedding Models

[Open interactive explainer](https://vickie02736.github.io/paper-webpages/papers/nv-embed/)

Static HTML explainer using the shared Research Atlas dark theme, header and section navigation. Complete Chinese and English versions support `?lang=zh`, `?lang=en` and the site language preference. Three reading depths remain available; language switching preserves selected nodes, masks, training stages, sliders, charts and quiz answers. No ChatGPT sign-in is required.

Source: [ICLR 2025 paper](https://proceedings.iclr.cc/paper_files/paper/2025/hash/c4bf73386022473a652a18941e9ea6f8-Abstract-Conference.html)
