DRO：单条反馈也能用于对齐

从提示、回答、标量反馈三元组出发，以正则化最优策略的关系构造平方目标；在实现中必须保留 soft advantage 的含义。

Offline Regularised Reinforcement Learning for Large Language Models Alignment · 2405.19107v1

原论文 ↗人工智能与计算
01

研究问题

偏好对通常给同一问题的两份答案排序；单条反馈则只给一份答案打分或点赞。DRO 研究怎样用后一类数据更新模型。参考策略提供概率锚点，正则项约束偏离；soft value 是与问题及策略相关的学习量，不是随意选取的常数。

DPO 通常需要成对偏好，而用户的点赞或评分往往只对应单条回答。Richemond 等人的 DRO 研究这种离线反馈，联合学习策略与 soft value；它与若干同名的点式对齐或扩散模型方法不是同一篇工作。

02

方法怎样工作

  1. KL 正则化最优策略满足 π*∝πref exp(r/τ)，其中归一化项可写成 exp(V*/τ)。对这一关系取对数，得到奖励、soft value 和策略 log-ratio 之间的方程，再最小化残差平方。
  2. 原始 DRO-V 同时学习 Vϕ 与 πθ。对策略求导，可重写为奖励减 value 的 log 概率项与二次 log-ratio 惩罚。verl 接收外部构造的优势，并不在这个损失函数内部自动训练原文的 value 网络。

03

从符号到目标

R 是标量反馈，τ>0 为正则尺度，Vϕ 近似与正则化策略有关的 soft value，不能随意替换为任何均值而声称目标不变。第二式采用 verl 的记号；πold 与原始 πref 的角色需由调用方明确。

LDRO-V = ½ E[(R − Vϕ(x) − τ log(πθ(y|x)/πref(y|x)))²]
Jverl = Σt [log πθ(yt|st) At − β/2 · (log πθ − log πold)²]

演示固定 A 和旧概率，改变当前概率与 β，显示奖励项、二次项及总目标。这只比较固定优势下的单 token 目标形状，不重现 DRO-V 的 value 学习、离线数据分布或整体训练。

原文附录 B 还提出 DRO-P：消去最优 soft value 后，得到残差的条件方差目标。精确估计该方差需要同一提示下的多条回答；实际 Algorithm 2 为适配单回答数据，在批次维度近似这一方差（Eq.15）。因此，DRO-V、DRO-P 的批次近似和 verl 接收外部优势的损失应分别识别，不能由目标形式相似就断言实现等价。

06

适用条件与局限

离线数据覆盖、奖励质量和 value 近似误差仍影响优化。二次惩罚约束的是采样 log-ratio，不等于精确完整分布 KL，也不能独自保证任意 off-policy 数据上的稳定性。

当前概率等于旧概率时，二次 log-ratio 惩罚是多少？整个训练目标也为零吗？

展开推理

log(π/πold)=log 1=0，因此惩罚为零。奖励项 log π·A 通常仍非零；没有惩罚不等于没有更新信号。
