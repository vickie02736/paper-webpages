DAPO：让长推理训练继续学习

把裁剪、有效问题采样、token 权重和超长奖励一起纳入设计，解决长链推理中的探索与训练稳定性问题。

原论文 ↗人工智能与计算
01

研究问题

语言模型按概率逐个生成 token，答案可长可短。训练会提高相对好答案的概率。“裁剪”是限制某个样本继续推动目标的程度；“过滤”是决定样本是否进入更新；“惩罚”则先改变评分。三者作用在不同位置，因此不能把一个按钮当成另一个的替代。

朴素 GRPO 在长推理中可能出现熵坍缩、零优势组比例增加、长答案权重失衡，以及截断造成的奖励噪声。DAPO 的贡献是一个可复现的训练系统及其组件，而不只是一条新损失。

02

方法怎样工作

  1. Clip-Higher 分开设置 εlow 和 εhigh，增加正优势动作向上的空间。动态采样过滤全对或全错的奖励组并补采，直到积累足够有效问题；这会改变训练批次的组成并产生额外采样。
  2. 有效 token 统一平均，使长答案内的每个 token 不再被逐答案平均额外稀释。超长过滤与软惩罚处理截断噪声：一个控制损失掩码，另一个改变奖励，它们不能混写为同一操作。

03

从符号到目标

第一式省略采样条件和奖励模型以突出聚合。第二式是缓冲区内的教学写法：L 为最大长度，B 为缓冲宽度，T 为生成长度，惩罚系数取 1；硬截断及其 mask 另行处理。

J = E[Σi,t min(ri,t Ai, clip(ri,t, 1−εlow, 1+εhigh) Ai) / Σi Ti]
Rlength = −clip((T−(L−B))/B, 0, 1)

动态采样条件对二值正确性为 0<正确答案数<G。对于一般实数奖励，应检查组内是否有变化，不可简单套用正确率阈值。演示同时显示裁剪目标、组是否保留和长度惩罚。

适用条件与局限

启发式之间有交互，收益依赖模型、数据与上下文预算。扩大上裁剪边界不是保证探索改善的定理，也不能保证所有模型免于熵坍缩。

教学例 L=100、B=20 中，长度 90 的惩罚是多少？全对组会因此保留下来吗？

展开推理

长度惩罚为 −(90−80)/20=−0.5。组过滤是另一个判断：按演示的二值正确性规则，全对组仍被丢弃。
