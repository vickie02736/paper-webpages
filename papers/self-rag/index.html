01 · Intuition / 直觉

为什么“固定检索”仍然不够？

普通 RAG 会把 top-k passages 一股脑交给模型；Self-RAG 把“检索是否有帮助”本身也变成模型要学习的判断。

Conventional RAG / 传统 RAG

总是检索，可能带来噪声

写“我最好的暑假”时，外部文档不一定有帮助；把无关 passage 加进上下文，反而限制模型的表达。

固定 top-k ≠ 固定相关性。论文指出，检索结果可能 off-topic，且模型不一定真正遵循证据。
Self-RAG

按需检索，再给每段打分

模型先生成 Retrieve = Yes / No / Continue，只在需要时调用 retriever；然后对相关性、支持度和有用性进行自评。

关键转变：检索不再是外接的固定前处理，而是生成过程中的可控动作。
一句话理解

像一位会查证的写作者

中文

先判断这句话是否需要事实依据；需要就查资料；写完后逐句核对，再留下最可信的版本。

另一种说法

先判断是否需要证据，只在有帮助时检索，再逐段批评并保留最好的延续。

论文概览

三项核心贡献

  1. 训练单一 LM 自适应检索并生成 reflection tokens。
  2. 用 ISREL / ISSUP / ISUSE 细粒度评估 evidence 与 output。
  3. 推理时用阈值、权重和 segment-level beam search 控制行为。

04 · Deep dive / 数学

让“可靠”成为可调节的解码目标

Self-RAG 的关键不是单一分数，而是把不同 critique token 的概率作为可组合的控制信号。

分段评分 · 式（3–4）
f(yt, d) = p(yt | x, d, y<t) + S(Critique)
S = ΣG∈{ISREL, ISSUP, ISUSE} wG · sG

生成质量与自评质量线性加权。把 wISSUP 调高，会偏向更有证据支持的候选。s_G 为类内归一化的批评分数；Appendix A.4 对部分支持计半分，并把有用性 1–5 映射到 −1 至 1。滑块仅说明偏好，不预测实验指标。

当前倾向：在可信度和可读性之间保持平衡。
自适应检索 · Appendix A.4 阈值
retrieve if  p(Yes) / [p(Yes)+p(No)] > δ

δ 越高，触发检索越少；这使同一个模型可以在 fact-heavy 任务中更谨慎，在开放式写作中更自由。

主张支撑证据尚存的不确定性
完整方法优于总是检索 top 1 的消融版本Figure 3a 中 Retrieve top 1 在 PopQA / ASQA 上下降；Figure 3c 另展示阈值对检索频率的影响。该消融同时改变检索时机与候选文档数，不能单独归因于按需检索；跨领域表现也未被完整验证。

Self-RAG 更事实可靠Bio 的 FactScore、ASQA citation precision/recall 等指标领先多种基线。论文伦理声明也承认输出仍可能没有被引用完全支持；不能等同于无幻觉。

Explain it yourself / 自测

为什么 Self-RAG 不直接使用 top-k passages？

因为检索并不总是必要，且 passage 可能不相关。模型先预测 Retrieve，再决定是否把检索纳入当前 segment。

ISREL 和 ISSUP 有什么区别？

ISREL 问“这份证据对问题有用吗”；ISSUP 问“生成的陈述被这份证据支持到什么程度”。

为什么提高 ISSUP 权重会降低 MAUVE？

Figure 3b 报告提高 ISSUP 权重时引用精度上升、MAUVE 下降；这是该实验中的观测权衡，不能仅凭此图断定更长或更流畅的候选被过滤。

Self-RAG 是否消除了 hallucination？

没有。论文在 Ethical Concerns 中明确承认，生成内容仍可能没有被引用完全支持。
