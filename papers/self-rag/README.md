# Self-RAG — Learning to Retrieve, Generate, and Critique through Self-Reflection

Bilingual interactive paper explainer using the shared Research Atlas dark reading style.

Use the shared header to navigate sections, choose a reading depth, and switch between Chinese and English. Language links (`?lang=zh` / `?lang=en`) and the remembered `atlas-lang` preference work across the site. Paper-specific diagrams, experiment values, and selected interaction states are retained when switching languages.

Shared presentation assets: [`../../assets/paper.css`](../../assets/paper.css) and [`../../assets/paper.js`](../../assets/paper.js).

Source: [ICLR 2024 paper](https://proceedings.iclr.cc/paper_files/paper/2024/hash/25f7be9694d7b32d5cc670927b8091e1-Abstract-Conference.html)
