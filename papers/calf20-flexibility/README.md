# CALF-20 flexibility explainer

`index.html` is a bilingual Research Atlas explainer for Oktavian et al., “Gas adsorption and framework flexibility of CALF-20 explored via experiments and simulations”, *Nature Communications* 15, 3898 (2024), DOI [10.1038/s41467-024-48136-0](https://doi.org/10.1038/s41467-024-48136-0).

The page is built from the supplied article PDF, supplementary methods/figures PDF, peer-review file and source-data workbook. Interactive values are labelled as reported points, source-data summaries or qualitative teaching diagrams. The evidence ledger is in [`sources.md`](sources.md).

The hero and structure section display attributed original Figure 1 viewports, with a link to the complete source page. The publication recheck in `sources.md` records the connectivity, chart-scale and transition-direction corrections.

Publication-time authors, affiliations and paper dates are rendered from the shared catalogue metadata; see [bibliographic evidence](sources.md#bibliographic-metadata) and the [metadata guide](../../references/paper-catalog-guide.md#authors-affiliations-and-paper-dates). Paper dates are separate from this explainer’s creation/publication/update dates.
