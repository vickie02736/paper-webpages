熵机制：探索为何过早耗尽

策略越来越确信已有答案时，训练可能失去探索空间。论文从概率与更新的协方差解释熵变化，并选择性约束高协方差 token。

The Entropy Mechanism of Reinforcement Learning for Reasoning Language Models · 2505.22617v1

原论文 ↗人工智能与计算
01

研究问题

若下一步只可能选两种动作，[0.5,0.5] 比 [0.99,0.01] 更难预测。熵把这种不确定程度变成一个数；它不判断哪个答案正确。logit 是生成概率前的可调分数，softmax 把分数转为和为 1 的概率。提高一个 logit，通常会提高对应动作的概率。

熵衡量一个分布的不确定性，不直接衡量答案质量。该研究观察到多次推理 RL 实验中熵快速下降，随后性能饱和。其拟合关系 R=−a exp(H)+b 是特定训练条件下的经验描述，不能当作所有模型的普适定律。

02

方法怎样工作

  1. softmax 概率由 logits 决定。若更新进一步偏向已经高概率的动作，分布可能更集中；若提高稀有动作的概率，熵可能增加。影响还取决于完整分布与更新方向，不能只根据单个 token 的奖励下结论。
  2. Clip-Cov 选择性屏蔽某些高协方差 token 的更新，KL-Cov 对高协方差 token 加入约束。论文也比较普通熵奖励和参考 KL：稳定熵本身并不保证更高性能。

从符号到目标

这里 log 使用自然对数，熵单位为 nat。最后一式为 softmax 在小 logit 扰动下的一阶教学展开：dp= p(dz−Epdz)，代入 dH=−Σ log(p)dp 得到协方差形式。有限步长时，页面直接计算更新前后的熵，而不把一阶近似当作精确值。

H(p) = −Σa pa log pa
pa = exp(za) / Σb exp(zb)
ΔH ≈ −Cov a∼p(log pa, Δza)

演示只有两个动作，分别控制初始概率与一个 logit 的增量。它解释熵变化的方向；完整 Clip-Cov/KL-Cov 还需要批次统计、选择阈值和损失定义，不能从这个二动作图复现实验结果。

原文 Eq.10 在一批采样 token 上定义 Cᵢ=(log πᵢ−平均 log π)(Aᵢ−平均 A)。Clip-Cov 在指定协方差区间内随机选取一小部分 token，将其梯度置零；KL-Cov 选择协方差排名最高的一小部分，并对这些位置加入旧策略到当前策略的 KL 惩罚（Eqs.11–14）。这与简单扩大 PPO 概率比裁剪区间不同。

06

适用条件与局限

熵与性能之间的相关性、拟合和机制分析各有适用范围。高熵可能对应多样的好答案，也可能对应无效或随机输出；需联合评估质量、长度和采样预算。

从 p=0.5 出发，只提高动作 1 的 logit，熵会上升还是下降？

展开推理

分布从最均匀状态偏向动作 1，熵下降。但这个变化并不能判断动作 1 是否正确，也不能单独证明训练性能提高或下降。
