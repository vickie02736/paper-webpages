# DeepRAG — Thinking to Retrieve Step by Step for Large Language Models

[Open interactive explainer](https://vickie02736.github.io/paper-webpages/papers/deeprag/) · [English version](https://vickie02736.github.io/paper-webpages/papers/deeprag/?lang=en)

A bilingual explainer using the shared Research Atlas dark theme and chapter navigation. Explore the five-step reasoning walkthrough, MDP actions, binary search tree, reward sliders, backbone results, retrieval-cost scatterplot, knowledge map and quiz at three reading depths.

Language switching preserves the selected interactions and follows the site's `?lang=` and `atlas-lang` conventions. The static page uses the repository's local shared assets; no sign-in or external runtime is required.

Source: [ICLR 2026 paper](https://proceedings.iclr.cc/paper_files/paper/2026/hash/bdff657cb9351656c025da8e1dc538a4-Abstract-Conference.html). Paper values, equations and source locations are retained.
