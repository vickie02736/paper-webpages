## 全部可视模块与状态

1. `#glance` 三张数字卡与推理 / 检索 / 终止概览：25.41% 是 Abstract / §1 的作者概述，页面未把它换算为百分点或推广到单个 benchmark；5 个数据集见 §4，0–2 检索轮数是 §5.3 / Figure 3 的分布概述。流程依据 Figure 1（p.1）、§3.1（pp.3–4），是推理过程摘要，不表示离线训练时才运行的树搜索会在每次线上推理时穷举。
2. `#intuition` 电影例子与五步切换：Figure 1。电影识别使用参数知识，各片时长由检索提供，178 + 179 + 201 = 558 分钟。检索分别对应三部电影；五步卡片明确合并重复步骤，树的第二次局部分叉只显示第一部时长。这是一条示例轨迹，不保证任意模型都记得标题或都需要查时长。
3. `#method .mdp-graph` 状态链和三个动作按钮：§3.1。链只画 continue 转移；terminate 直接产生最终答案，不经过下个子问题。参数答案不加检索成本，检索答案加一。r 包含中间答案及被检索文档；输出文本为教学说明，不运行 LLM。
4. 三组件卡片：Figure 2（p.3）、§3.2–3.4、Algorithm 1（p.5）。二叉树用于离线合成轨迹；校准的 offline / online 是从 DeepRAG-Imi 出发的两个选项，不是必须依次执行的阶段。
5. `#tree` 五个可点击节点：Figure 2、Algorithm 1。页面仅展示两次局部分叉，第二对节点只沿第一对的参数分支继续，另一子树明确省略；不是完整二层树。优先队列优先探索低检索数，正确答案和预算限制共同约束可用轨迹。
6. `#deepdive` 奖励公式与计算器：Eq.(3)（p.6）、§4.2（p.7）。完整列出格式错误 0、格式正确但错误答案 0.1、正确答案 `1 − α min(T, retrievals)` 三种情况。论文 α=0.1、T=5；滑块是数学教学参数。检索次数扩展至 8 以展示上限饱和，α 范围收至 0–0.15，保证此教学范围内正确答案最低奖励仍高于错误格式合规奖励。所有选择的输出都走同一分段函数；说明文字明确 α=0 时没有检索惩罚，次数达到 T 后奖励不再下降。
7. 模仿学习 Eq.(1) 及符号说明：§3.3（p.5）。保留原文 `−Σ log[Pr(q)+Pr(a)]` 这一写法，没有擅自替换为常见的两个 log 之和。未检索时 d 为 null；检索文本 loss masking 见同节。
8. 研究层校准说明及两张校准卡片：Eq.(2)、§3.4、Appendix B.3。离线偏好优化与在线 GRPO 的用途区分正确；检索 token 被 mask。
9. `#backbone` 两种 backbone / 每种七条柱：Table 1（p.7）。14 个数值与原表一致。原页面把 Avg 误标为平均 EM；复算表中十个 EM/F1 分数可确认 Avg 同时平均五个数据集的两种指标，现已明确。42.36、41.05 等值不变。去掉原文未用于 backbone 名称的 Reasoning 后缀。柱长按数值 / 45 计算，显示共同零起点 0–45 刻度。
10. `#tradePlot` 十一种方法的散点状态：Table 2（p.8）。所有 EM / All retrievals 值一致；现将点映射至标明刻度的 x=0–5、y=10–35 轴，明确 y 截断。FLARE / DRAGIN 的零检索来自该实验的默认阈值，不是无检索功能；不把所有方法说成被同一 DeepRAG 变体全面支配。
11. 效率 / 知识边界两张数据卡：Tables 2–3（p.8）。RLon EM=30.00、0.14 次、0.40 秒；与 IterDRAG 比较明确。RLoff EM=32.70、0.28 次，属于另一工作点。Balanced accuracy=0.801、MCC=0.543 与原表一致，限定为 2WikiMultihopQA。
12. 实验设置与批判性理解卡片：§4.2–5。每个训练数据集 4,000 个 imitation、1,000 个 calibration；OOD 列表正确。更强 retriever、长文档与开放式生成的建议属于讲解者提出的待验证方向。
13. `#map` 七个外围可点击节点、中心、五条记忆点：§1–5。连接线表达论述关联，不是模型计算拓扑。
14. 三道双选自测的正确 / 错误反馈：§3.2–3.4；第三题关于持续检索成本与噪声对应 §5.2 / Figure 5。答案不将“检索越少”误读为不顾正确率。
