01

研究问题

条件概率是在“此前已经生成这些文字”的前提下，下一步取某个 token 的概率。整段文字的概率是每一步条件概率的乘积。因此，每一步看起来很小的概率偏差，也可能随着回答变长而累积；对数把乘积变为和，只改善数值计算，不消除统计风险。

只比较最后一个 token 的条件概率，通常不足以修正整条轨迹的分布。自回归生成的状态就是已经生成的前缀，因此此前动作也影响当前状态出现的概率。

02

方法怎样工作

  1. 若目标 π 的支持包含在行为分布 μ 的支持中，则 Eπ[f]=Eμ[(π/μ)f]。在相同初始状态和环境转移下，轨迹密度比中的环境项消去，留下动作概率比的连乘。
  2. 三策略解耦进一步把 πθ/μ 分为 πθ/πold 与 πold/μ。PPO 的裁剪已经改变原始重要性采样目标；随后叠加权重截断或拒绝掩码，应逐项说明引入的近似。

03

从符号到目标

使用 log 空间累加能缓解数值溢出，但不消除统计重尾。ESS 是批次权重集中的诊断量，不是对相关样本真实独立数量的精确计数；当所有权重为零时应报告不可定义。

W(τ) = ∏t π(at|st)/μ(at|st) = exp(Σt log ρt)
ESS = (Σi Wi)² / Σi Wi²
Eμ[min(W,C) f] ≠ Eπ[f]  (in general)

演示设每步条件概率比相同，只改变比值与序列长度，显示逐 token 比值、序列乘积和截断后乘积。这是量级示意，不是假设真实语言模型每步比值恒定，也不是训练曲线。

怎样阅读证据
