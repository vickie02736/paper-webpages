OTB：让基线随 token 改变

用生成过程累计的梯度能量估计每个位置的奖励基线，减少长序列中的方差，并避免把 padding 当作真实样本。

01

研究问题

同一批答案的长度不同，为了放进矩形数组，短答案后面会补 padding。补位不是真实生成的动作，必须从计算中排除。OTB 还让基线随 token 位置变化，使用到该位置为止累积的“梯度能量”代理，而不把整条长答案都当成一个均匀对象。

组均值给整条答案一个相同优势，但不同 token 的不确定性和梯度规模不一样。全局最优基线还可能依赖未来 token 的能量。OTB 推导 token 层次的基线，再用前向概率构造可计算代理。

02

方法怎样工作

  1. 对于采样 token y，softmax log 概率对 logits 的梯度是 one-hot(y)−p，其平方范数为 1−2p(y)+Σv p(v)²。将这些非负量累计到当前 token，得到 realized-energy 代理。
  2. 在同题多条回答之间，用累计能量加权当前位置的回报。仅有效 token 参与基线和输出优势；已经结束的回答不靠 padding EOS 稀释仍在生成的回答。

03

从符号到目标

G 是当前位置的 reward-to-go，m 是有效 token 掩码，ε 为数值稳定项。末端二值奖励的演示把相同结果奖励传播到此前有效 token；密集奖励或多轮工具任务必须重新定义 reward-to-go 和掩码。

wt = 1 − 2p(yt) + Σv p(v)²; Wt = Σj≤t wj
B̂t = Σi mi,t Wi,t Gi,t / (Σi mi,t Wi,t + ε)
Ai,t = mi,t (Gi,t − B̂t)

logit 梯度并非整个网络的精确梯度。论文利用最后层及 RMSNorm 的结构解释代理，并讨论向主干推广所需假设。总体基线理论与同组有限样本估计的性质分开说明。

06

适用条件与局限

代理、掩码和基线依赖的处理决定实现含义。组大小为 1 时基线接近自身回报，学习信号可退化；极小权重和全 padding 状态也必须显式处理。

当只有轨迹 1 还有有效 token、它的回报为 1 时，此位置的基线和优势是什么？

展开推理

只剩一条带非零权重的轨迹，基线为 1，轨迹 1 优势为 0；轨迹 2 是 padding，权重与优势都为 0。这也说明有效样本太少会让信号退化。
