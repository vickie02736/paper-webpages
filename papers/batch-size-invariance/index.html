批量大小不变性：拆开 PPO 的两个参照

批量缩小后，怎样保留相近的学习行为？从三个策略的职责，到 EWMA 年龄、步长换算与 Procgen 消融。

01

批量变小，为什么行为也变了

批量大小 B 是一次更新使用多少个样本。减小 B 通常能省显存，却会让更新更频繁、梯度更嘈杂。这里“不变性”的意思是：适当调整参数后，消耗同样多环境样本时，学习表现能大致保持接近；不是每一步参数完全相同，也不是运行时间相同。

普通 PPO 让同一个旧策略兼任两职：说明数据是怎样采出来的，以及规定新策略不要离谁太远。批量变小会改变这个参照的“年龄”，所以只改学习率仍可能改变优化行为。论文把这两个角色拆开。

  1. 行为策略 πbehav：确实生成这批数据，负责重要性采样的分母。
  2. 近端策略 πprox：近期模型的参数平均，负责限制更新幅度。
  3. 当前策略 πθ：正在被优化；既与数据来源比较，也与近期参照比较。

重要性权重是“目标动作概率 ÷ 采样动作概率”，用来修正抽样偏好。近端的含义是“靠近当前模型的参照”。优势 A 是动作相对基准表现的估计，正值希望增加其概率，负值希望降低。

02

一个目标中的两个参照

w = πprox(a|s) / πbehav(a|s)
r = πθ(a|s) / πprox(a|s)
Lclip = Ebehav[w · min(rA, clip(r, 1−ε, 1+ε)A)]
LKL = Ebehav[(πθ/πbehav)A − λ KL(πprox ∥ πθ)]

s 是环境状态，a 是采样动作，Ebehav 表示按实际采样数据取平均。ε 是裁剪宽度，λ 是 KL 惩罚强度（原文用 β；这里改写以免与平均衰减率混淆）。行为与近端策略都视为固定，梯度只通过当前策略。

未裁剪时 w·r=πθ/πbehav，近端策略恰好消去；它只决定裁剪或惩罚发生在哪里。不能把 πprox 当作数据来源来替换重要性采样分母。这个动作层面的修正也不等于已经完全修正任意陈旧数据的状态分布和优势估计。

03

让学习进度按样本数对齐

SGD（随机梯度下降）按当前小批样本估计的改进方向更新参数。Adam 还根据过去梯度的平均与大小，自适应地调节各参数的步幅。PPG（分阶段策略梯度）把策略学习与辅助学习分成阶段，因此还需要控制每个阶段使用的样本数。

EWMA 是指数加权移动平均：越新的模型参数权重越大，只保存一个平均模型就能概括一段历史。论文平均的是网络参数，不是动作概率。每次策略梯度更新后更新平均；PPG 的辅助阶段结束后，在下一个策略阶段重新初始化平均。

H = βprox / (1 − βprox)
Bnew = B / c
Hnew = cH                 βprox,new = cH / (1 + cH)
αSGD,new = α / c          αAdam,new = α / √c
Nπ,new = cNπ             Wadv,new = cWadv

H 是稳态 EWMA 的平均年龄，单位为梯度步；βprox 越接近 1，参照越旧。c 是批量缩小倍数。把每步样本量降为 1/c、把 H 增为 c 倍，H×B 这个按样本数衡量的年龄保持不变。Wadv 是估计优势均值与方差的有效迭代窗口，Nπ 是 PPG 每个阶段的策略迭代数。

为何 Adam 与 SGD 不同？在梯度噪声占主导的小批量区间，Adam 的均方根梯度分母随批量缩小约增大 √c，已经抵消一部分步幅；因此外部步长再除以 √c，而 SGD 使用线性缩放。超出这个条件，规则可能不再保持行为。

用样本数衡量参照的年龄

附录 A 对有限历史使用归一化 EWMA：wnew=1+βw，θprox←θ/wnew+βwθprox/wnew；初始化 θprox=θ、w=1。因此 H=β/(1−β) 是稳态年龄，而不是第一步就精确成立。Adam 的 β₁、β₂ 可另取 β₁^(1/c)、β₂^(1/c)，但主实验多未使用这一可选调整。

05

何时可用，何时需要重新验证

适用条件不能省略：优化批次需足够小；论文的不变性实验同步改变优化批次与迭代批次，且 Eπ=1。多次重复遍历极小批次会反复利用同一批数据，不能自动套用相同结论。

Heist 是明显例外；附录 D 调整 Adam 的 β₁、β₂ 仍未消除差距。PPG 辅助阶段为控制耗时，还保留了每 worker 的 minibatch 大小并采用单独的步长调整。这里没有证明任意任务、任意大批量或 LLM 后训练都满足不变性。

平均模型需要额外参数存储和前向计算。原文估计，不含环境执行的计算开销增加约 PPO 30%、PPG 2.3%；其实现的实际运行时间增幅为 19% 和 3%。样本效率与运行效率是两种不同指标。

假设批量缩小 4 倍：仅把 Adam 步长除以 2、但不改 βprox，会发生什么？

展开推理

优化器采用了平方根缩放，但参照平均年龄 H 仍是 8 个梯度步。每步样本数变成四分之一，因此样本尺度年龄由 65,536 降为 16,384。把 H 改为 32、βprox 改为 32/33，才能恢复原样本尺度年龄；优势窗口和 PPG 阶段设置仍须一起考虑。

与 Rollout 校正专题的联系：它为“采样策略”和“近端参照”应分开的设计提供原始论文依据。TRM 则进一步讨论长序列上的分布偏移和拒绝掩码；两篇论文的任务、假设与实验对象不同。
