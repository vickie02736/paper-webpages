# MOF water stability: from labels to evidence

Bilingual interactive explainer of Burtch, Jasuja and Walton, *Chemical Reviews* (2014), DOI [10.1021/cr5002589](https://doi.org/10.1021/cr5002589).

[Open the explainer](index.html) · [Evidence ledger](sources.md)

Read the original four stability categories alongside a separate evidence-confidence axis, then inspect application tests and six SI material dossiers. Coverage includes water affinity, flexible phases, mixed-component capture, kinetic/thermodynamic distinctions, coating trade-offs and an explicitly labelled extension to REE adsorption.

The complete scientific article, main figures/tables and all 36 SI pages were reviewed. Historical labels and conflicting reports remain qualified by their original conditions.

Catalogue integrated; first-publication date 2026-11-02. Full static, production bibliography, catalogue/taxonomy and all-43-page browser checks pass (3,649 interaction actions).
