01 · Intuition

为什么“只靠模型记忆”不够？

先不看公式。把语言模型想成一个很会说话、但不一定知道今天新闻的回答者。

01

记忆藏在参数里

它可以学到大量事实，但很难直接指出“这句话来自哪里”，也很难只改掉其中一条。

可追溯性
02

世界会变化

如果领导人、价格或规范变化，重新训练整个模型代价很高。

可更新性
03

生成容易“顺口但不真”

纯生成器可能会把语言流畅度当成事实可靠性，产生 hallucination。

事实性
一个类比

闭卷答题 → 开卷答题，但答案仍由生成器组织

传统 closed-book 模型只从参数中“回忆”。RAG 先从外部索引找出若干段文字，再让 BART 读着这些证据写答案。检索到的内容不是硬拷贝，而是一个可以被生成器综合、改写和补全的潜变量。

02 · Landscape

RAG 填补了哪条缺口？

论文把已有路线放在一条连续光谱上：只靠参数、只做抽取、或把检索真正接进生成。

三条路线

Closed-book参数记忆；灵活生成
→
问题难更新、难溯源
Retrieve-and-extract从文档抽取答案 span
→
问题不能综合线索、受文档原句限制
RAG检索作为 latent variable
→
目标生成灵活 + 外部证据可更新

贡献判断：已知、改进、真正的新组合

Already known

DPR dense retrieval、BART seq2seq、Wikipedia 文档索引。

Incremental improvement

对检索文档数、解码方式和任务适配进行系统化探索。

Fundamental novelty

把检索文档作为 latent variable，用概率边缘化把“查到什么”与“生成什么”连起来，并在多个知识密集型任务上统一微调。

训练时没有直接告诉模型“该检索哪一篇”。只对最终答案的 marginal likelihood 计算损失；查询编码器和 BART 一起更新，文档编码器与索引固定。
Step 1 · Retriever

先把问题变成向量

查询编码器 BERTq 把输入 x 映射为向量 q(x)。文档编码器 BERTd 预先把每个文档映射成 d(z)。

输入问题：“Hemingway 写过哪些小说？”
输出q(x)，用于和所有文档向量做内积比较
Step 2 · Non-parametric memory

在 21M 个文本块里找 top-K

使用 Maximum Inner Product Search（MIPS）近似找出概率最高的文档。这里的记忆是原始文本，所以人可以阅读、编辑、替换。

索引December 2018 Wikipedia dump；每篇文章切成不重叠的 100-word chunks
输出z1…zK 与 pη(z|x)
Step 3 · Parametric memory

BART 读问题 + 文档来写

把 x 与检索文本 z 直接拼接，交给 400M 参数的 BART-large 生成输出 token。

输入x、z、已生成的前缀 y1:i−1
输出每个候选文档下的 pθ(yi|x,z,…)
Step 4 · Latent document

不押注单篇文档：把它们边缘化

模型不需要显式标签告诉它“正确证据是哪一篇”。训练目标直接最大化答案概率，让检索器学会为生成器提供有用的上下文。

训练− log p(y|x)，Adam；只微调 BERTq 与 BART
结果检索和生成被同一个最终任务信号耦合
Step 1：编码问题
把自然语言问题投影到检索空间，准备与文档向量进行相似度比较。
04 · Deep dive

RAG-Sequence 与 RAG-Token：差别就在边缘化的位置

两种公式来自论文 Section 2.1。下面把“同一文档”与“每个 token 可换文档”拆开。

Equation 1–2
pRAG-Sequence(y|x) ≈ ∑z∈top-K pη(z|x) · ∏i pθ(yi|x,z,y<i)
先对每个文档生成完整序列概率，再在文档层面求和。整段输出共享同一个 z。

Sequence：整段答案押一个文档

z₂→TheSunAlsoRises

适合一篇文档提供完整叙事；解码需要对每个文档分别 beam search。

Token：每个 token 可以换证据

z₂→Sunz₁ → A Farewellto Arms

适合把多篇文档的线索拼到一句话里；可以直接接标准 beam decoder。

Hemingway 例子：外部记忆负责“引导”，参数记忆负责“完成”

论文 Figure 2 观察到：生成 “Sun” 时，提到 The Sun Also Rises 的文档后验更高；生成 “A Farewell to Arms” 时，另一篇文档占优。标题开头被引出后，后验变平，说明 BART 自己已经能完成标题。

论文事实

索引可解释、可写入

原始文本让人能检查被访问的知识，也能通过编辑索引更新记忆。

应当追问

检索到 ≠ 证据充分

论文展示了检索命中与生成质量，但没有把“证据可靠性”变成独立监督信号。

我的分析

RAG 不是自动事实核查器

它能降低幻觉、提供来源线索，但外部库本身可能不完整、有偏或过时。

07 · Knowledge map

最后只记住五件事

01

RAG = 参数记忆 + 外部文本记忆。

02

文档 z 是 latent variable，不需要逐条检索标签。

03

Sequence 共享文档；Token 可按 token 换文档。

04

可微检索与生成器可端到端共同适配任务。

05

替换索引即可更新世界知识，但无法消除来源偏差。
