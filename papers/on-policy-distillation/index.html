同策略蒸馏：在学生走过的路上教它

学生先生成自己的轨迹，教师再对这些前缀给出分布反馈。训练时见到的状态因而更接近学生推理时真正遇到的状态。

On-Policy Distillation of Language Models: Learning from Self-Generated Mistakes · 2306.13649v3

原论文 ↗人工智能与计算
01

研究问题

蒸馏是让较小的学生模型学习教师的输出分布。分布不只是一个“标准答案”，还包含每个候选 token 的概率。同策略的关键在于由学生先写出前缀，再请教师对这个前缀点评，因此教师能看到学生实际会犯错的状态。

传统序列蒸馏主要使用教师答案，学生训练时很少见到自身错误造成的前缀。GKD 把数据分布选择和散度选择一起设计：不仅问“模仿什么分布”，还问“在哪些状态上模仿”。

02

方法怎样工作

  1. GKD 用比例 λ 混合学生生成数据与固定监督数据。在选定前缀上计算教师与学生的 token 分布差异，然后直接对学生参数反向传播；采样到的序列在这一步视为固定。
  2. 后续 Thinking Machines 与 verl 的 PG OPD 把 logν(y)−logπ(y) 作为采样 token 的反馈，再进行策略梯度。其 stop-gradient、奖励符号和采样分布不能与 GKD 的直接散度梯度混写。

03

从符号到目标

ν 为教师、π 为学生。forward KL 更重视覆盖教师概率质量，reverse KL 常呈寻模态倾向，但效果取决于任务和解码。单个采样的 log 概率差可为负，KL 的非负性只适用于完整期望。

DF = Σv νv log(νv/πv); DR = Σv πv log(πv/νv)
LGKD = (1−λ) Edata[D] + λ Ey∼π[D]
rPG(y) = sg[log ν(y) − log π(y)]

演示用“教师常见前缀”和“学生错误前缀”两种教学状态，保持教师在各状态的条件分布不同。切换状态后重新计算完整二分类散度，说明监督分布会随前缀变化，而不是把教师固定成一个无条件标签。

06

适用条件与局限

教师也可能在学生错误前缀上给出不可靠反馈；词表、分词器和概率接口影响可用信号。减少状态分布失配并不保证学生纠正所有错误，也不保证超越教师。

某个采样 token 的 log 教师概率减 log 学生概率为负，是否违反 KL 非负性？

展开推理

不违反。单个 token 的差值可为负，KL 非负性描述完整分布上的期望；而这里的反馈还是 reverse KL 的负向信号，必须同时核对方向和采样分布。
